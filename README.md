# Theta Country Resort — Website Demo

A mobile-first hospitality website concept for Theta Country Resort in Juja, Kenya.

## Technology
- HTML
- Tailwind CSS CDN
- Custom CSS
- Vanilla JavaScript
- Font Awesome CDN

## Features
- Responsive landing page
- Room enquiry modal
- Simulated M-Pesa interaction
- Conference enquiry via WhatsApp
- Dining enquiry
- Google Maps directions
- Floating WhatsApp contact

## Important
This is a demonstration website. Room prices and amenities are illustrative and must be verified by the resort. The M-Pesa flow is simulated and does not process payments.

## Run locally
From this folder, run:

python3 -m http.server 8090 --bind 127.0.0.1

Then open http://127.0.0.1:8090/
